Synthetic raster, polygon and DEM fixtures are generated in temporary directories or intercepted browser requests. **They are never written to `public/data/` or presented as geographic evidence.** Their test provenance is explicitly synthetic. Passing comparison tests does not validate a real historic shoreline.

Screenshots are generated by Playwright in ignored `test-results/atlas-desktop.png` and `test-results/atlas-mobile.png`. Browser tests cover the real bundled geographic vectors; screenshot appearance alone is not geospatial validation.

Expected limits / warnings:

- No actual historical-water, affected-settlement, archive-media or regional-terrain validation could run because those inputs were not acquired. They remain explicitly unavailable in the site.
- Default layer toggles control empty evidence layers; no visual historical boundary change is claimed.
- Build reports a nonfatal >500 kB chunk advisory, primarily from MapLibre. The current main JS is about 390 kB gzipped. Production build succeeds; future code-splitting can reduce initial overhead.
- Rasterio's Affine compatibility and headless-browser environment emit nonfatal dependency/environment warnings. No TLS, checksum or assertion was disabled.
- Browser runs used Chromium software WebGL. Other browser/driver combinations and new-task restoration were not independently tested.
- Production startup and validation are local only. Nothing was published or pushed, and no environment configuration was changed.
